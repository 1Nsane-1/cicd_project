# CI/CD Pipeline Dashboard

C++17 сервис и веб-интерфейс для автоматизации процессов сборки, юнит-тестирования, развертывания проектов и выполнения плагинов.

---

## 🚀 Возможности

- **Сборка (Build):** Компиляция C++ исходников с поддержкой флагов линковки (включая Winsock `-lws2_32`).
- **Тестирование (Test):** Компиляция и запуск модульных тестов с выводом результатов.
- **Развертывание (Deploy):** Автоматическое копирование скомпилированных артефактов и веб-ресурсов в директорию деплоя.
- **Динамические плагины (Plugins):** Подгрузка и исполнение внешних C++ DLL-модулей во время выполнения.
- **Веб-Дашборд:** Мониторинг статуса выполнения пайплайна и просмотр логов в реальном времени.
- **Корректная кодировка логов:** Встроенная конвертация вывода консоли Windows (CP866/OEM) в UTF-8 для отображения кириллицы в браузере без «кракозябр».

## 📁 Структура проекта

```text
.
├── src/
│   ├── main.cpp            # Точка входа HTTP-сервера
│   ├── pipeline.h          # Логика выполнения этапов пайплайна
│   ├── process_runner.h    # Запуск внешних процессов и перекодировка CP866 -> UTF-8
│   ├── json.h              # Парсер конфигурации JSON
│   └── plugin_interface.h  # Интерфейс для динамических DLL-плагинов
├── tests/
│   └── sample_test.cpp     # Модульные тесты проекта
├── web/                    # Фронтенд дашборда (HTML, CSS, JS)
├── bin/                    # Скомпилированные исполняемые файлы
├── deploy/                 # Директория целевого развертывания
├── pipeline.json           # Конфигурация этапов пайплайна
├── build.bat               # Скрипт сборки проекта
└── README.md               # Документация
🛠️ Требования
Операционная система: Windows 10 / 11

Компилятор: MinGW-w64 (g++ с поддержкой стандарта C++17)

Библиотеки: WinAPI, Winsock2 (ws2_32)

⚙️ Сборка и запуск
Скомпилируйте проект:
Запустите скрипт сборки в консоли:

DOS
.\build.bat
Запустите сервер:

DOS
.\bin\app.exe
Откройте веб-интерфейс:
Перейдите в браузере по адресу:

Plaintext
http://localhost:8080
📄 Конфигурация (pipeline.json)
Этапы пайплайна задаются в файле pipeline.json:

JSON
{
  "pipeline": [
    {
      "stage": "build",
      "source": "./src",
      "output": "./bin"
    },
    {
      "stage": "test"
    },
    {
      "stage": "deploy",
      "source": "./bin",
      "target": "./deploy"
    }
  ]
}
🔧 Частые ошибки и решения
Символы `` (кракозябры) в логах: Вывод консоли Windows декодируется из OEM-кодировки (CP866) в UTF-8 внутри process_runner.h с помощью функции `MultiByteToWideChar`.

Ошибка ld.exe: undefined reference to ...: При работе с сокетами Windows убедитесь, что при сборке передается параметр -lws2_32.
```
